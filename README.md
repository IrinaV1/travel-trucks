## About the Project

**TravelTrucks — Find the perfect camper for your next adventure.**

TravelTrucks is a camper rental web application designed to help users find a camper for their next trip. Users can browse available campers, explore their features and specifications, view photo galleries, and submit booking requests.

The application includes a home page, a camper catalog, and individual camper detail pages, providing a convenient way to explore campers and plan a trip.
## Features


- **Home Page** — introduces the TravelTrucks application and helps users start exploring campers.
- **Camper Catalog** — displays available campers with their photos, prices, ratings, and locations.
- **Camper Details** — provides detailed information about each camper, including specifications and a photo gallery.
- **Load More** — allows users to load additional campers in the catalog.
- **Booking Form** — allows users to submit a booking request for a selected camper.
- **Form Validation** — validates user input before submitting the booking form.
- **Responsive Design** — optimized for desktop screens, with tablet and mobile improvements planned.


## Tech Stack


- **Next.js** — React framework for building the application.
- **React** — for building user interfaces.
- **TypeScript** — for type-safe JavaScript development.
- **TanStack Query** — for managing server state and fetching camper data.
- **Axios** — for making HTTP requests to the API.
- **CSS Modules** — for component-scoped styling.
- **Formik** — for managing form state.
- **Yup** — for form validation.
- **Swiper** — for the camper image gallery.
- **Vercel** — for application deployment.

### Prerequisites

Make sure you have Node.js and npm installed.

## Quick Start

Clone the repository:

```bash
git clone https://github.com/IrinaV1/travel-trucks.git
```

Navigate to the project directory:

```bash
cd travel-trucks
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file based on `.env.example` and configure the required environment variables.

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. 
You can use the hosted campers API (`https://campers-api.goit.study`) as the backend, so you don't need to run a separate backend server.
## Usage

1. Open the [TravelTrucks website](https://travel-trucks-six-gold.vercel.app/).
2. Explore the home page.
3. Navigate to the camper catalog.
4. Browse available campers and click **Load More** to see additional listings.
5. Select a camper to view its details, specifications, and photo gallery.
6. Fill out the booking form to submit a booking request.
